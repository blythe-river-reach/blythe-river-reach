Keep this site afloat 🛟

A free, one-person project — the data is public, the domain and upkeep aren’t. If the tide times saved you a wasted trip to the ramp, you can toss a few bucks in the tip jar. No account needed; the site stays free either way.

Build 2026-09-29d — redesign preview · 14-day outlook · push alerts · classic layout · GitHub data relay · no server functions.
Place timing is estimated from Reclamation river miles and the measured pulse travel speed.
How the data flows: your browser fetches the USGS gauges live on every load. Reclamation’s servers don’t allow browser access, so a GitHub robot gathers their river sensors, Lake Havasu’s level, and the dam-schedule PDFs several times an hour and publishes them for this page.
 All values are provisional. This is not a flood-warning system. Times are Arizona (MST).
